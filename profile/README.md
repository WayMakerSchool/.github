# 🧭 WayMakerSchool

## 👋 Welcome!

**WayMakerSchool** Organization에 오신 것을 환영합니다!

이곳은 WayMakerSchool 멤버들이 함께 만든 프로젝트를 기록하고, 서로의 배움을 나누는 공간입니다.
언어나 분야에 상관없이, 우리가 만들어 가는 성장의 과정을 살펴보고 가세요!

## 📌 시작하기 전에 읽어주세요

- 📝 **[README 템플릿](https://github.com/WayMakerSchool/readme-template)**: 프로젝트 README는 이 템플릿으로 작성해 주세요.
- 🏷️ **저장소 이름 규칙**: `연도-프로젝트-팀이름`
  - 예시: `2026-web-Chefs`, `2026-hackathon-WayMakers`
  - 영어 소문자, 숫자, `-`만 사용해 주세요. (팀이름은 대문자 허용)
